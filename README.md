# Kotlin Playground

A personal Android playground project for experimenting with Kotlin and Jetpack Compose.

## Tech stack

- Kotlin
- Jetpack Compose
- Gradle (Kotlin DSL)

## Requirements

- Android Studio (or the Gradle wrapper + Android SDK)
- minSdk 24, targetSdk/compileSdk 37

## Build

```
./gradlew build
```

Or open the project in Android Studio and run the `app` configuration.
